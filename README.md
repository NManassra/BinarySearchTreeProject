# Student Records with a Binary Search Tree

> Supporting — Algorithms · Birzeit University Computer Engineering portfolio

A C-based student record manager supporting insert, search, update, delete, and persistent file storage.

## What this demonstrates

- C
- binary search trees
- CRUD operations
- file I/O
- data modeling

## Repository contents

The implementation is in `P3_1212359_NouraManassra_Section5.c`; `studentData.txt` contains sample data.
